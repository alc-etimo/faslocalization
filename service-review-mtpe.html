The LQA workflow.

01

Review the raw output

Not every MT error is equal. A terminology error changes the story; a register error changes the character. Read before you edit.

02

Post-edit with classification

Each edit gets a category and a severity. The log is the audit trail the PM reads, not the diff.

03

Run technical QC

Timing, CPS, spelling. The linguistic pass can be clean and the file still fail delivery.

04

Generate the delivery report

"All resolved" is the proof the client needs. The report closes the loop.
